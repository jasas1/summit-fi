How this library was built

Reference tracks were harvested from headphone-community threads (HiFi Guides, headphones.com, Reddit), deduplicated, and given short recording notes researched against Wikipedia, Discogs and MusicBrainz. A TypeSafe Jev model then scored each track 0–1 on six listening dimensions; plain code combines those into the per-profile composite you sort by here. Mean model confidence across the set is 0.79.

About the Qobuz links

A Play link goes straight to a Qobuz release that a TypeSafe Jev match confidently identified as the same recording; its quality badge is read from Qobuz metadata, not guessed. A Search link means no confident match — usually a classical work with many recordings — so it opens a Qobuz search to browse. Region and label still affect availability; check the release before adding it.

summit-fi is a personal listening reference, not affiliated with Qobuz, HiFiMan or Woo Audio. Track selections reflect forum opinion and model scoring, not measurement.
