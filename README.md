# summit-fi

A dark, single-page reference-track library for critical listening on a high-end
headphone system (built around a HiFiMan Susvara Unveiled + Woo Audio WA33).

Live: **https://jasas1.github.io/summit-fi/**

273 tracks harvested from headphone-community threads, given researched recording
notes, and scored by a TypeSafe Jev model on six listening dimensions (voice,
soundstage, dynamics, bass, transients, timbre). Plain code combines those into
three ranked profiles. The page has a sortable, filterable table, per-genre and
per-profile CSV downloads, and a Qobuz search link on every track.

## Contents

- `index.html` — the whole site (self-contained: styles, data and logic inline).
- `csv/` — importable playlists (title, artist, album): the complete library,
  one file per genre, and the three top-10s. Import at Soundiiz or TuneMyMusic.
- `.nojekyll` — serve files as-is on GitHub Pages.

## Notes

- Qobuz links are **searches**, not verified hi-res URLs; availability varies by
  region and label. Open a link and check the release badge.
- Track picks reflect forum opinion and model scoring, not measurement.
- Generated by the trackpicker pipeline; not affiliated with Qobuz, HiFiMan or
  Woo Audio.
